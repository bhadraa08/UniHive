UniHive 🐝
Your campus. Your people. Your hive.

UniHive is a student community platform designed to make college life more connected, collaborative, and engaging. It brings students together to ask academic questions, share study resources, find teammates for projects and hackathons, and help recover lost belongings—all in one place.

🌐 Live Demo: https://uni-hive-nu.vercel.app/  
💻 GitHub Repository: https://github.com/bhadraa08/UniHive

✨ Features

- 🎓 Student Community:A shared space for students to connect and participate in campus activities.
- 💬 Help Loop:Ask academic questions, offer help to peers, and mark requests as resolved.
- 📚 Academic Resources: Discover and share study materials, notes, code, slides, and cheat sheets.
- 🤝 Find Teammates: Discover students and connect with potential teammates for hackathons and projects.
- 🔎 Lost & Found: Help students report and recover misplaced campus belongings.
- 🏆 Hive Points: Earn points for helping others and resolving academic requests.
- 📊 Community Dashboard: Explore campus activities, recent requests, shared resources, and team openings.
- 👤 Student Profiles: Track your activity, responses, bookmarks, shared resources, and earned badges.
- 🔐 Authentication: Sign up, log in, and access a personalized student experience.
- 🎨 Interactive UI: Enjoy a responsive interface with a distinctive lavender-inspired visual identity and light/dark themes.

 🛠️ Tech Stack

- Frontend: React 19, TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS, custom CSS
- Icons: Lucide React
- Animations: Canvas Confetti
- State Management: React Context
- Browser Storage: LocalStorage and SessionStorage
- Deployment: Vercel

 🚀 Getting Started

Follow these steps to run UniHive locally.
 Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

 Installation

1. Clone the repository

```bash
git clone https://github.com/bhadraa08/UniHive.git
```

2. Navigate to the project directory

```bash
cd UniHive
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open the application

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

 💡 How It Works

1. Open UniHive and explore the introduction.
2. Register a student profile or use the available demo access.
3. Explore the dashboard and discover campus activities.
4. Ask for academic help, share resources, find project teammates, or browse lost-and-found posts.
5. Participate in the community and earn Hive Points through helpful contributions.

 🎯 Project Objective

The goal of UniHive is to create a more collaborative campus environment by bringing academic support, resource sharing, teamwork, and student interactions together on a single platform.

Instead of relying on scattered messages and separate platforms, students can use UniHive as a central space to discover opportunities and support one another.
